## ⚠️ Note on the Current State of the Schema

The file `01_schema_gerado_umltorel.sql` is the **auto-generated DDL** from
the UML class diagram (before the manual optimizations described in the
report, section 3.1). It uses generic types (`integer`, `text`) and composite
keys inherited directly from the generalization/composition of the class
model.

The **final optimized schema** (`INT AUTO_INCREMENT` keys, `VARCHAR(N) NOT NULL`,
`UNIQUE`, refactoring of `estabelecimentos`, `responsavel` and `vagas`, as
described in sections 3.1.3 to 3.1.5 and documented in the report's data
dictionary) was done directly in phpMyAdmin. The `.sql` script for that final
schema will be added in a future update - see `docs/relatorio_projeto.pdf`,
section 3, and the attached data dictionary for the full detail of each
table, type, and constraint.

## Recommended Execution Order

1. `schema/01_schema_gerado_umltorel.sql` - creates the base tables and foreign keys
2. `procedures/sp_atualizar_media_estabelecimento.sql` - must exist **before** the triggers that call it
3. `triggers/01_turma_limites.sql`
4. `triggers/02_notas_validacao.sql`
5. `triggers/03_disjoint_hierarquia_utilizador.sql`
6. `triggers/04_responsavel_estabelecimento_coerencia.sql`
7. `triggers/05_nota_final_automatica.sql`
8. `triggers/06_media_estabelecimento_automatica.sql`

## About the Triggers and the Procedure

These files were extracted from the project report (Annexes 9 to 24) and
reorganized by business rule, so they can be executed directly on a
MySQL/MariaDB engine.

Each business rule implemented by a trigger is documented in the header of
its respective `.sql` file, with a reference to the report section where it
is justified.
